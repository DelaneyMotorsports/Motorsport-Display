# Motorsport-Display

A high-performance motorsport dashboard application built with Qt/QML for displaying real-time CAN bus telemetry data.

## Project Structure

This repository contains the **Reikon Dash** application, a customizable motorsport display designed to run on embedded hardware.

### Getting Started

Navigate to the [reikon-dash/](reikon-dash/) directory for the complete application:

```bash
cd reikon-dash
```

See [reikon-dash/README.md](reikon-dash/README.md) for detailed documentation, build instructions, and usage information.

## Features

- Real-time CAN bus integration
- Customizable Qt/QML dashboard layouts
- Cross-platform support (Linux embedded & desktop)
- Qt Design Studio compatible UI workflow
- Comprehensive logging and diagnostics
